# SteelSense AI — frontend

React + TypeScript + Vite chat dashboard for the SteelSense AI backend.

```bash
npm install
cp .env.example .env   # point VITE_API_BASE_URL at the backend if not localhost:8000
npm run dev
```

Requires the FastAPI backend (`src/backend/api`) running separately — see the
repo root README for the full local setup.
