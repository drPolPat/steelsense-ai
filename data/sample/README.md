# Sample data

Everything in this directory is **synthetic and illustrative**. It is
generated by [`src/backend/data/generate_synthetic_data.py`](../../src/backend/data/generate_synthetic_data.py)
for a fictional structure ("Ironwood Crossing Bridge") and does not
represent any real sensor deployment, structure, or measurement.

To regenerate:

```bash
python -m src.backend.data.generate_synthetic_data
```

(Generation is deterministic — seeded with `RANDOM_SEED = 42` — so
regenerating produces byte-identical output.)

## Files

- **`sensor_readings.csv`** — hourly readings from 8 simulated Hall-effect
  sensors over a 60-day window: `timestamp`, `sensor_id`, `location`,
  `reading_mv`, `temperature_c`.
- **`sensors.json`** — structure and sensor metadata (locations,
  descriptions, baseline values).
- **`scenario_ground_truth.json`** — documents exactly which sensors carry
  an injected anomaly and how it was parameterized (gradual fatigue drift,
  an acute stress spike, or cross-sensor divergence). This is an answer
  key for later evaluation, not an input the agent sees.
